# B4 + B11: future-information leaks in the Test head

Dir: appwrite/functions/train-win-probability. Test: test/asof-test-leaks.test.js (3 tests).

## Leaks
1. N6/B4a followedOn. src/training.js `longRows` computed it from `match.innings.length > 2`, true on every row of the match including innings 1-2. Now computed inside the innings loop as `idx >= 2 && innings[1].team === innings[2].team`; serving flags it from Cricbuzz isFollowOn on that innings, so it is as-of.
2. B4b strength. src/build.js counted every training-window match, including the row's own result. New `AsOfWinRates` (training.js; lookup before record, key = teamKey, shrunkWinRate, 0.5 unseen) is walked in date order inside `fitLongModel`; every format is recorded (keys include format). Removed the whole-window counters. `exportTeams` (shipped tables) is unchanged. Caveat: like AsOfState, "before" means earlier in the sorted walk; a same-day or still-running Test counts.
3. N1/B11 scheduledDays. src/corpus.js used `info.dates.length` (days played). Now 5 for TEST, 4 otherwise, matching match-sync cricbuzz.js:1153. It feeds `longMatchBalls` (ballsTotal, ballsRemaining) and the scheduledDays feature.

Other whole-match reads in the Test row builder: none. `longOutcomeFor` is the label; `innings.length === 0` is a guard. Serving differences: none beyond these (winprob.js defaults 5, main.js 2992 `?? 5`).
