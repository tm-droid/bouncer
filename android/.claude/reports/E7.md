## followedOn leak

The lab computed `followedOn` per match, knowing it before innings 3. The trainer's B4 fix computes it as of the row. Fixed in 9e6e6f54 (`idx >= 2 && innings[1].team === innings[2].team`). Baseline effect: pooled log-loss 0.76334 (leaked) -> 0.76435 (as-of), +0.00101; ECE 0.04451 -> 0.04319. Leaked-run Δs are not used anywhere above.

## Recommendation

- Test head: keep v5/v6 as is. Do not ship the added features or the two-stage head. Re-test `+declared` with a real declaration flag (the proxy is noisy) before spending more on it.
- Trainer: no change needed for Test. If B3 routes FC to the Test head, the trainer needs no new model; keep the legal-ball guard and as-of followedOn (already there).
- Serving (B3): route first-class non-Test long-format matches to the Test head instead of undetermined, and report them as a 3-class output; the measured gain over a draw-rate prior is -0.14 to -0.15 log-loss. Keep orientation via `orientToTeam1` (draw belongs to neither side).
- Calibration: add a 3-class calibration measure before any future Test-head gate.
