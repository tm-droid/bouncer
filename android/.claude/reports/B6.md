## Checks, tests, tolerances
1. Test head (`model.long`). Refused when: previous had one and this has none; `trainingRows` is 0; holdout log-loss is not finite; neutral class probabilities are not finite or do not sum to 1 (1e-6). Log-loss regression uses `GATE_LOG_LOSS_SLACK` (0.02), but only when `previous.long.holdout.leakFixed === true`. The manifest has no version, so the fit now writes `leakFixed: true` on the Test holdout; an older published figure was measured with the `ballsBowled` leak and is not comparable, so the check is skipped (also skipped when previous has no figure). Tests: "the Test head: absent is fine, dropped is not, ..." and "regresses only against a published model measured after the leak fix".
2. First-innings sanity: T20 230/4 after 120 balls must score > 0.6, 70 all out < 0.4. Test: "first innings: a big total must favour the batting side" (zero weights and inverted weights both fire).
3. `full` tier gets every check core gets (ECE, sanity cells, first-innings, monotone grid, prematch); messages are prefixed "(with elevens)" / `.full`. Elevens are neutral (`xiStrength(null)`). Tests: "the full variant gets the same checks as core"; the good full model passes.
4. Chase monotonicity grid per format (T20, ODI, HUNDRED): balls-used fraction {0.25, 0.6} x runs multiple of par pace {0.4, 0.8, 1.2, 1.6} x wickets lost {0, 3, 6, 9}. More wickets in hand, or fewer runs needed at the same balls, must never lower P by more than `GATE_MONOTONE_SLACK` 0.005. The first violation is reported ("chase: not monotone, T20: ..."). Coarse on purpose: cheap, and slack absorbs the logistic head's tiny non-monotone wiggles. Test: "chase monotonicity" (negative squared-wickets weight; inverted runs-needed weight).
5. As-served score: `SERVED_FLOOR`/`SERVED_CEILING` (0.03/0.97) apply to a new `servedLogLoss` on every tier holdout and head holdout; existing logged metrics are unchanged. The regression gate compares as-served on both sides when both report it, else raw on both (like with like). Tests: "gate log-loss is the as-served figure ..." and "the clamp the gate applies is the one match-sync serves" (regex on `match-sync/src/winprob.js`).
